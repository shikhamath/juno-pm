## Problem & user

RocketShip PMs need this handled: Juno is an assistant that helps me manage customer feedback and turns them into prioritized backlog as well as executive summary; points out risks and highlights key recommendations and priorities. It helps me create an executive dashboard as well. Juno does this inside limits a human set on purpose, and defends every call it makes.
